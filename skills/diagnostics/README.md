# Diagnostics skills

Read-only health checks for Tailnet / Coolify inventory consumers.

| Skill | Role |
|-------|------|
| [`check_tailnet_urls`](check_tailnet_urls/SKILL.md) | Probe UI URLs from app-dashboard inventory |
| [`diagnose_tailnet_service`](diagnose_tailnet_service/SKILL.md) | Deep-diagnose one MagicDNS hostname |

Shared Python lives in the package module [`src/diagnostics/`](../../src/diagnostics/).
